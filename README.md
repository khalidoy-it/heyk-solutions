# Heyk-Solutions - Professional Digital Agency Website

A modern, responsive single-page website for Heyk-Solutions - an expert digital agency specializing in building websites, SaaS platforms, and scalable business solutions.

## About Heyk-Solutions

Heyk-Solutions is a professional digital agency specializing in:
- Creating and building high-performance websites
- Developing scalable SaaS platforms
- Shipping complete digital solutions
- Providing expert digital strategy consulting

## Website Features

Single-page website with the following sections:
- **Hero Section** - Showcasing expertise and services
- **Services** - Core expertise and offerings
- **Portfolio** - Case studies and project showcases
- **Client Reviews** - Testimonials with 5-star ratings and reviews
- **Contact** - Contact form and company information

## Technology Stack

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (via CDN)
- **Material Symbols** - Icon library
- **Space Grotesk & Inter Fonts** - Modern typography
- **Dark Mode** - Built-in dark theme with neon blue accents
- **Responsive Design** - Mobile-first approach

## Deployment to GitHub Pages

**For complete deployment instructions including custom domain setup, see [DEPLOYMENT.md](./DEPLOYMENT.md)**

### Quick Start

1. Create a GitHub repository (must be public for free Pages)
2. Upload all files including `index.html` and `.nojekyll`
3. Enable GitHub Pages in repository Settings → Pages
4. Your site will be live at `https://[your-username].github.io/[repository-name]/`

### Custom Domain Setup

If you have purchased a custom domain:

1. Create a `CNAME` file with your domain name
2. Configure DNS records at your domain registrar
3. Enable HTTPS in GitHub Pages settings
4. See [DEPLOYMENT.md](./DEPLOYMENT.md) for detailed instructions

## Customization

- Email: `hello@heyk-solutions.com`
- Contact form fields as needed

Edit footer section in `index.html` to add your social media URLs:
- Twitter
- GitHub
- LinkedIn

- **Company Name**: Update "Heyk-Solutions" throughout `index.html` if needed
